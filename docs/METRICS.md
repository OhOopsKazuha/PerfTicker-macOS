# 数据口径与限制


1. CPU 总负载、逐核负载来自 Mach CPU tick 差分。逐进程 CPU 来自 libproc 累计时间差分，并按 Mach 时钟比例换算；CPU% 归一化为整机 0–100，与活动监视器单核心 100% 的显示口径不同。12 核机器上一个核满载约显示 8.3%。首个采样预热，不计作行情。
2. 内存为 `(活跃页 + 有线页 + 压缩器页 − 可清除页) × 页大小` 的估计，限制于物理内存范围。其口径不完全等于活动监视器；不将该值解释为内存压力。进程内存是 RSS，多个进程间共享页会重复计入。
3. GPU 来自 IOAccelerator 驱动的 PerformanceStatistics。字段存在时显示真实值；没有字段时显示“—”。GPU 内存使用是驱动报告的系统内存使用量，属于统一内存，不能与系统内存直接相加，也不代表独立显存。
4. CPU/GPU 频率、GPU 温度、功耗、风扇、逐进程 GPU 当前未实现。逐核列表显示负载，不伪造逐核频率。
5. 磁盘吞吐来自 IOBlockStorageDriver 的累计读写字节差分。接口不可用时显示“—”。网络合计处于启用状态的 en* 接口，排除 lo / utun，可能包含虚拟接口或多链路重复流量；不是互联网流量计费依据。
6. 部分系统进程的详细信息受权限限制，无法读取的进程不会出现在列表中。进程终止发送 SIGTERM，需二次确认并校验 PID 和启动时间；可能被拒绝或被目标进程忽略。不会使用管理员提权强制结束。
7. GPU、磁盘和网络没有逐进程归因时，右侧明确提示不支持，不以 CPU 排行代替。
8. K线下方“采样量”是每根K线内真实样本点数，属于展示辅助，不是证券成交量。长期历史不落盘，退出后清空；设置和营收保存在本地 WebKit 存储中。
9. 桌面模式是全窗口点击穿透的展示模式，无局部可点击控件；通过顶部菜单栏“退出桌面模式”恢复普通窗口。只作用于主屏，Spaces / 全屏应用 / 多屏组合尚未完整验证。
10. 虚拟营收只用于娱乐，未复刻 Windows 版的硬件权重和温度惩罚，也不能代表真实工作量、设备性能或经济收益。暂停时不结算；超过 5 秒的采样间隔只按 5 秒结算，避免休眠后用过期读数大量结算。
