# PerfTicker for macOS · ARM64 预览版

基于 QiuSui1145/PerfTicker 的视觉与功能概念制作的 macOS 本地版本。原作者：QiuSui / QiuSui_Studio；原项目：https://github.com/QiuSui1145/PerfTicker 。本移植为非官方版本，按 GPL-3.0 提供源码。

## 启动

双击同目录的 **PerfTicker.app**。不需要安装 .NET、Node 或其他运行时。

目标平台为 Apple Silicon，最低构建目标 macOS 13。实际验证环境为本机 M4 Pro / macOS 27.2，其他芯片和系统版本尚未实测。

应用仅作本地临时签名，尚无 Apple Developer ID 签名和公证。若系统阻止运行，可在确认来源后通过“系统设置 → 隐私与安全性 → 仍要打开”处理。无需关闭系统安全保护。

建议将应用复制到“应用程序”后使用。关闭窗口后仍在菜单栏运行；菜单栏“▥ PT”可恢复窗口。⌘Q 或菜单栏“退出”完全结束。

## 已实现

- 原版风格的深色行情终端、浅色主题、指数条、自选列表、主图、主力动向、逐笔事件与进程表。
- CPU 整机和逐核负载、内存、交换空间、GPU 总占用及 GPU 内存使用、磁盘读写、网络上下行、进程 CPU / 内存 / 线程。
- 2 / 5 / 10 / 30 / 60 秒 OHLC K 线，MA5/10/20，十字光标与 OHLC 提示，最近一小时内存历史。采样间隔 0.5 / 1 / 2 / 5 / 10 秒；K线周期不低于采样间隔两倍。
- 进程搜索、CPU / 内存 / 线程排序；右键置顶、复制进程名、请求结束进程。
- 暂停、窗口置顶、红涨/绿涨切换、菜单栏常驻、桌面展示模式。
- 本地虚拟营收、设置与营收保存；按真实采样时间结算。缺失的 GPU 数据不产生收益或空转费用。

## 快捷键

- ⌘F：搜索进程
- 空格：暂停 / 继续
- 1–5：K线周期
- E：营收开关
- T：窗口置顶
- C：红涨 / 绿涨
- Esc：关闭对话框或菜单
- ⌘Q：退出

## 数据口径与限制

1. CPU 总负载、逐核负载来自 Mach CPU tick 差分。逐进程 CPU 来自 libproc 累计时间差分，并按 Mach 时钟比例换算；CPU% 归一化为整机 0–100，与活动监视器单核心 100% 的显示口径不同。12 核机器上一个核满载约显示 8.3%。首个采样预热，不计作行情。
2. 内存为 `(活跃页 + 有线页 + 压缩器页 − 可清除页) × 页大小` 的估计，限制于物理内存范围。其口径不完全等于活动监视器；不将该值解释为内存压力。进程内存是 RSS，多个进程间共享页会重复计入。
3. GPU 来自 IOAccelerator 驱动的 PerformanceStatistics。字段存在时显示真实值；没有字段时显示“—”。GPU 内存使用是驱动报告的系统内存使用量，属于统一内存，不能与系统内存直接相加，也不代表独立显存。
4. CPU/GPU 频率、GPU 温度、功耗、风扇、逐进程 GPU 当前未实现。逐核列表显示负载，不伪造逐核频率。
5. 磁盘吞吐来自 IOBlockStorageDriver 的累计读写字节差分。接口不可用时显示“—”。网络合计处于启用状态的 en* 接口，排除 lo / utun，可能包含虚拟接口或多链路重复流量；不是互联网流量计费依据。
6. 部分系统进程的详细信息受权限限制，无法读取的进程不会出现在列表中。进程终止发送 SIGTERM，需二次确认并校验 PID 和启动时间；可能被拒绝或被目标进程忽略。不会使用管理员提权强制结束。
7. GPU、磁盘和网络没有逐进程归因时，右侧明确提示不支持，不以 CPU 排行代替。
8. K线下方“采样量”是每根K线内真实样本点数，属于展示辅助，不是证券成交量。长期历史不落盘，退出后清空；设置和营收保存在本地 WebKit 存储中。
9. 桌面模式是全窗口点击穿透的展示模式，无局部可点击控件；通过顶部菜单栏“退出桌面模式”恢复普通窗口。只作用于主屏，Spaces / 全屏应用 / 多屏组合尚未完整验证。
10. 虚拟营收只用于娱乐，未复刻 Windows 版的硬件权重和温度惩罚，也不能代表真实工作量、设备性能或经济收益。暂停时不结算；超过 5 秒的采样间隔只按 5 秒结算，避免休眠后用过期读数大量结算。

## 源码与构建

`Source/` 包含 Swift 原生窗口、C 系统采集器和本地 HTML/CSS/Canvas 界面，无第三方运行时依赖，无远端字体、脚本或服务。

安装 Apple Command Line Tools 后，在终端执行 `bash Source/build.sh`，输出 `dist/PerfTicker.app`。构建脚本默认使用 `/Library/Developer/CommandLineTools`。最低目标版本是 13.0，但这不代表已完成所有旧版系统的回归测试。

`dist/PerfTicker.app/Contents/MacOS/PerfTicker --self-test` 可输出两次真实采样差分后的 JSON。
`--smoke` 是开发验收模式：实际启动窗口、接收实时数据、检查界面操作与布局，截图后退出。此模式使用独立非持久化存储，不读取或清空日常使用配置。
