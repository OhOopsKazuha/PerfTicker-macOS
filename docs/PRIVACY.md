# 隐私与本地数据

应用采集本机 CPU、内存、GPU 驱动统计、磁盘/网络吞吐，以及可读取进程的名称、PID、CPU、RSS 和线程数。不会读取进程的命令行参数、文件内容、浏览记录或网络报文内容。

源码内无远程脚本、字体、分析服务或上传接口。界面资源随应用本地加载。GitHub 的网页、下载和自动构建服务是独立服务，其行为不属于应用的本地采样逻辑。

设置和虚拟营收存于本应用的 WebKit 本地存储；窗口几何由 macOS 偏好设置保存。最近一小时行情和事件仅在内存中保留，退出后丢弃。卸载应用本体不保证清除这些本地偏好。

`--self-test` 会向标准输出打印包含进程名称的真实 JSON；调试时请存放在本地，不要直接附在公开 Issue、日志或截图中。`--smoke` 使用独立的非持久化 WebKit 存储，检查不读取或清空普通运行模式的配置。

进程“全抛”操作在用户二次确认后发送 SIGTERM。应用不请求管理员权限，不绕过系统进程保护。
